This project uses practical AI techniques to look into high school data from Saudi Arabia and predict future academic performance. Education quality matters a lot to the local community, so having an early view of how schools are doing helps administrators act quickly when issues show up. We gathered real numbers from past years, mainly looking at student averages in Qudrat and Tahsili exams, along with official school evaluation results. By running machine learning models like Linear Regression, Random Forest, and XGBoost, our system picks up trends from older data to predict upcoming test performance. This gives school managers in Saudi Arabia a clear idea of which schools need extra support or better resources.
