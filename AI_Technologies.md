1- Data Preprocessing and Normalization : is the essential first step to prepare our raw school data for the machine learning models. First, we clean the dataset by removing incomplete school records and converting text-based percentages into workable numbers. Next, we apply Min-Max Scaling to compress all variables (like Qudrat and ETEC scores) into a uniform 0 to 1 range. This normalization guarantees that our AI algorithms evaluate all features fairly, preventing any bias toward variables with naturally larger numbers.

2- Multiple Linear Regression : is our primary model used to forecast a school's upcoming Tahsili average score based on multiple variables simultaneously. We selected this algorithm because it is highly interpretable and not a "black box", allowing us to extract the exact mathematical weight of each input feature. By analyzing past Qudrat scores and evaluation metrics, the model generates a clear equation. This transparency helps educational administrators easily understand exactly how much each specific factor impacts overall student performance.

3- Random Forest : We selected the Random Forest algorithm because relying on a single decision tree easily overfits the training data, leading to predictive mistakes. This ensemble method resolves this issue by combining multiple trees to select the most accurate outcome. For our project, we specifically apply it to calculate Feature Importance, identifying exactly which evaluation factors most strongly drive student academic results. Seeing these specific driving factors helps educational authorities make data-driven decisions and prioritize their interventions effectively.

4- XGBoost : is a flexible model we used for predicting a school's Tahsili score. Unlike Random Forest, which builds its trees separately, XGBoost builds them one after another, and each new tree fixes the mistakes of the previous ones. We selected it because it can find complex patterns between Qudrat, Internal Evaluation, and External Evaluation that a simple equation may miss. We compared it with Linear Regression and Random Forest using MAE, RMSE, and R², and we used 5-fold cross-validation to make sure the results are stable. This helps decision-makers choose the model that gives the best predictions to support the schools that need help.
